## MongoDB “Hello World” (dummy insert)

In this part you will write a simple Python program that can :

- connect to MongoDB
- insert a document
- read it back

This will form the basis for your Gateway program. 

**Do the following on your laptop.**

### 1) Create folder & Python Virtual Environment



**For Windows — PowerShell:**

~~~cmd
mkdir soil-gateway
cd soil-gateway

python -m venv .venv
Set-ExecutionPolicy -ExecutionPolicy Unrestricted
.\.venv\Scripts\Activate.ps1

pip install --upgrade pip
pip install pymongo
~~~

**For MAC/Linux**

```cmd
mkdir soil-gateway
cd soil-gateway
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install pymongo
```

### 2) Set Mongo env vars

##### For Windows — PowerShell:

Set for the current PowerShell session:

```
$env:MONGO_URL = "mongodb://localhost:27017"
$env:MONGO_DB  = "setu_soil"
```

Check they’re set:

```
echo $env:MONGO_URL
echo $env:MONGO_DB
```

Persist for your user account (optional — survives new terminals):

```
[Environment]::SetEnvironmentVariable("MONGO_URL", "mongodb://localhost:27017", "User")
[Environment]::SetEnvironmentVariable("MONGO_DB",  "setu_soil", "User")
```

> After setting persistent vars: close and reopen PowerShell (or restart the VS Code terminal).



#### For MAC/Linux

Set for the current terminal session:

```
export MONGO_URL="mongodb://localhost:27017"
export MONGO_DB="setu_soil"
```

Check they’re set:

```
echo $MONGO_URL
echo $MONGO_DB
```

Set just for one command:

```
MONGO_URL="mongodb://localhost:27017" MONGO_DB="setu_soil" python mongo_test.py
```

Make them persistent (optional):

- Bash: add to `~/.bashrc`
- Zsh: add to `~/.zshrc`

```
echo 'export MONGO_URL="mongodb://localhost:27017"' >> ~/.bashrc
echo 'export MONGO_DB="setu_soil"' >> ~/.bashrc
source ~/.bashrc
```

### Notes (all platforms)

- Use `mongodb://localhost:27017` if MongoDB is running on the same machine.
- If MongoDB is on another machine, replace `localhost` with its IP/hostname:



### 3) Create `mongo_test.py`

In the `soil-gateway`  folder, create the Python Script `mongo_test.py`:

```python
import os
import time
from pymongo import MongoClient

MONGO_URL = os.getenv("MONGO_URL", "mongodb://localhost:27017")
MONGO_DB = os.getenv("MONGO_DB", "setu_soil")

client = MongoClient(MONGO_URL)
db = client[MONGO_DB]

col = db["telemetry_events"]

doc = {
    "source": "mongo_test",
    "device_id": "dummy-sensor",
    "soil_moisture": 123,
    "received_ts": time.time(),
}

result = col.insert_one(doc)
print("Inserted _id:", result.inserted_id)

latest = col.find().sort("received_ts", -1).limit(1)
for row in latest:
    print("Latest row:", row)
```

### 4) Run it

To check if it's all working successfully, run the script and check if documents are created in  Mongo. 

```
python mongo_test.py
```

### Verify data is being stored

Open **MongoDB Compass**

Connect using:

```
mongodb://localhost:27017
```

Browse `setu_soil` → collections → documents

**Expected output**

- an inserted document

✅ Once this works, Mongo connectivity is proven.
