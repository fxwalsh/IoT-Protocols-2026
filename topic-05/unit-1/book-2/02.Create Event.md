# Movement Event 

Events are used to track, log, and work with important events. In this section, you'll define an event to track unexpected movements of the movement detection device.

+ In the Blynk Console, do to Developer Zone -> My Templates
+ Select the **Movement Detection Template** and open the "**Events & Notifications**" tab.

   <img src="./img/02.Create Event/image-20241202170316532.png" alt="image-20241202170316532" style="zoom:67%;" />

## Create Event from Movement Detection Device

Now that you have defined an event, lets update the code on the Raspberry Pi to create an event every time the Grove button is pressed. In this lab, a button press represents a movement event.

+ If not already open, open the ``blynk_movement.py`` script you created in the last step.

+ Add the following line of code inside the `is_movement_detected()` function

  ```python
  blynk.log_event("movement_event") # Has to match name of event in Blynk, including case!!!
  ```

+ Run the program again(or stop/start it if already running)

+ Activate the PIR to generate an event.

+ Now go back to the Device in the BLynk Console and select the Bell icon to open the Notifications and Events history. You should see the movement event created by the button press.
