# 4. Python and BLE

## The `bleak` package

`bleak` is a Python package for working with Bluetooth Low Energy devices. It provides a simple cross-platform API for scanning, connecting, reading characteristics, and receiving notifications.

For this lab, `bleak` is useful because it lets us write Python code that:

- finds BLE devices
- connects to the Polar H10
- subscribes to the Heart Rate Measurement characteristic
- reacts whenever a new heart rate value arrives

## A tiny example: connect to a BLE device

Create a file called ``tiny_ble.py``:

```python
import asyncio
from bleak import BleakClient

ADDRESS = "AA:BB:CC:DD:EE:FF" # Replace with your H10 address

async def main():
    async with BleakClient(ADDRESS) as client:
        print("Connected:", client.is_connected)

asyncio.run(main())
```

This program:

- creates a BLE client
- connects to the device with the given address
- prints whether the connection succeeded

## Very simple program for the Polar H10

The Polar H10 sends heart rate data through notifications on characteristic `0x2A37`.

Create a file called `polar_h10_simple.py`:

```python
import asyncio
from bleak import BleakClient

ADDRESS = "AA:BB:CC:DD:EE:FF"          # Replace with your H10 address
HR_CHAR_UUID = "00002a37-0000-1000-8000-00805f9b34fb"    # UUID for Heart Rate Measurement characteristic


def handle_hr(sender, data):
    heart_rate = data[1] # HR Value in index 1 
    print(f"Heart rate: {heart_rate} bpm")


async def main():
    async with BleakClient(ADDRESS) as client:
        print("Connected:", client.is_connected)
        await client.start_notify(HR_CHAR_UUID, handle_hr)
        print("Receiving heart rate notifications for 20 seconds...")
        await asyncio.sleep(20)
        await client.stop_notify(HR_CHAR_UUID)


asyncio.run(main())
```

Run it with:

```bash
python polar_h10_simple.py
```

## Code explaination

### Imports

- `asyncio` lets us run asynchronous Python code
- `BleakClient` is the object used to connect to the BLE device

### Address and characteristic UUID

- `ADDRESS` is the BLE address of your H10
- `HR_CHAR_UUID` is the full 128-bit UUID form of the Heart Rate Measurement characteristic

### Notification handler

The function `handle_hr(sender, data)` runs each time the H10 sends new heart rate data.

The heart rate packet begins with a **flags** byte. One important bit tells us whether the heart rate value is stored in:

- 8 bits, or
- 16 bits

The code checks that bit and then extracts the heart rate correctly.

### Main async function

Inside `main()` the program:

1. connects to the sensor
2. starts notifications on the heart rate characteristic
3. waits for 20 seconds while data arrives
4. stops notifications
