# 5. Recording and analysing HR data

## Goal

In this part of the lab, you will extend the earlier program so that it:

1. logs heart rate data to a file on the Raspberry Pi
2. calculates the user's heart rate training zone from a user-entered maximum heart rate

## Training zones

A simple five-zone model based on percentage of maximum heart rate is shown below:

- **Zone 1:** 50% to 60% of max HR
- **Zone 2:** 60% to 70% of max HR
- **Zone 3:** 70% to 80% of max HR
- **Zone 4:** 80% to 90% of max HR
- **Zone 5:** 90% to 100% of max HR

## Extended program

Create a file called `polar_h10_logger.py`:

```python
import asyncio
import csv
from datetime import datetime
from bleak import BleakClient

ADDRESS = "24:AC:AC:11:9C:6A"  # Replace with your H10 address
HR_CHAR_UUID = "00002a37-0000-1000-8000-00805f9b34fb"
LOG_FILE = "hr_log.csv"


def get_zone(hr, max_hr):    #HR zones based on % of max HR
    pct = (hr / max_hr) * 100

    if pct < 50:
        return "Below Zone 1"
    elif pct < 60:
        return "Zone 1"
    elif pct < 70:
        return "Zone 2"
    elif pct < 80:
        return "Zone 3"
    elif pct < 90:
        return "Zone 4"
    else:
        return "Zone 5"


def build_hr_handler(max_hr, filename):
    def handle_hr(sender, data):
        heart_rate = data[1]
        print(f"Heart rate: {heart_rate} bpm")

        timestamp = datetime.now().isoformat(timespec="seconds") # Get current time in ISO format
        zone = get_zone(heart_rate, max_hr)

        print(f"{timestamp} | HR: {heart_rate:3d} bpm | {zone}")

        with open(filename, "a", newline="") as f:
            writer = csv.writer(f)
            writer.writerow([timestamp, heart_rate, zone])

    return handle_hr


async def main():
    max_hr = int(input("Enter max heart rate: "))

    with open(LOG_FILE, "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["timestamp", "heart_rate_bpm", "zone"])

    handle_hr = build_hr_handler(max_hr, LOG_FILE)

    async with BleakClient(ADDRESS) as client:
        print("Connected:", client.is_connected)
        await client.start_notify(HR_CHAR_UUID, handle_hr)
        print("Logging heart rate for 30 seconds...")
        await asyncio.sleep(30)
        await client.stop_notify(HR_CHAR_UUID)

    print(f"Data saved to {LOG_FILE}")


asyncio.run(main())
```

## How the extended program works

### Logging to a file

The program creates a CSV file called `hr_log.csv` with three columns:

- timestamp
- heart rate in bpm
- training zone

This file can later be opened in Python, a spreadsheet, or another analysis tool.

### User-entered maximum heart rate

At the start of the program, the user enters a maximum heart rate value, for example:

```text
Enter max heart rate: 190
```

The program uses this value to classify each new reading into a zone.

### Console output

While the program runs, it prints something like:

```text
2026-03-08T11:14:02 | HR: 132 bpm | Zone 3
```
