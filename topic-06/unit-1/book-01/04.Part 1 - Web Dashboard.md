## Part 1: Flask Web Dashboard

Now create a **web App** that:

- Reads `state/doorbell.json`  

- Serves `static/last_visitor.jpg`  

- Shows them on a page with a friendly message  using  `template/stat`  

  

Install Flask into your current Virtual Environment

```
pip install flask
```

**NOTE: You may get a warning about a dependency Flask-SQLAlchemy - you can ignore this.**



In the /week10-lab1/templates folder, create a file called `status.html` with the following template for our dashboard

~~~html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <title>Smart Doorbell</title>
  <meta http-equiv="refresh" content="10"> 
  <style>
    body { font-family: sans-serif; max-width: 640px; margin: 2rem auto; text-align: center; }
    img  { max-width: 100%; height: auto; border-radius: 12px; box-shadow: 0 0 12px rgba(0,0,0,0.25); }
    .meta { margin-top: 1rem; color: #444; }
  </style>
</head>
<body>
  <h1>Smart Doorbell</h1>

  {% if last_event %}
    <p class="meta">
      Last press: <strong>{{ last_event.time_str }}</strong><br>
      ({{ last_event.age }} seconds ago)
    </p>
    <img src="{{ url_for('static', filename='last_visitor.jpg')  }}">
  {% else %}
    <p>No doorbell presses recorded yet.</p>
  {% endif %}
</body>
</html>
~~~





Create `web_dashboard.py` with the following content

```python
#!/usr/bin/env python3
import os, json, time, datetime
from flask import Flask, render_template

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
STATE_DIR = os.path.join(BASE_DIR, "state")
STATE_PATH = os.path.join(STATE_DIR, "doorbell.json")

app = Flask(__name__, static_folder="static")

def load_state():
    try:
        with open(STATE_PATH) as f:
            data = json.load(f)
        ts = data.get("ts")
        if not ts:
            return None
        age = int(time.time()) - ts
        time_str = datetime.datetime.fromtimestamp(ts).strftime("%Y-%m-%d %H:%M:%S")
        data["age"] = age
        data["time_str"] = time_str
        return data
    except FileNotFoundError:
        return None
    except Exception as e:
        print("Error loading state:", e)
        return None

@app.route("/")
def index():
    last_event = load_state()
    return render_template(
        'status.html',
        last_event=last_event
    )

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8000)
```

Start the Flask server:

```bash
source .venv/bin/activate
python web_dashboard.py
```

Leave it running.

## Test the whole lot

1. **In one terminal** on the Pi 4: run the camera app(if not already running)

   ```bash
   cd ~/smart-doorbell
   python doorbell_camera.py
   ```

2. **In another terminal**: run the web app(if not already running)

   ```bash
   cd ~/smart-doorbell
   python3 web_dashboard.py
   ```

3. From your **laptop or phone** on the same network:

   - Find the Pi 4’s IP:

     ```bash
     hostname -I
     ```

   - In a browser, go to:  
     `http://<pi4-ip-address>:8000/` or `http://hdiprpi:8000/`

4. Now press the Sense HAT joystick (middle) on the Pi 4.

   - The first terminal should show “Doorbell pressed!”.
   - The image and timestamp should update on the web page (it auto-refreshes every 10 seconds).

You’ve now built a working prototype **smart doorbell dashboard on Raspberry Pi 4 **
