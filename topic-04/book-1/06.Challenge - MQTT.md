# 6. Challenge: Publish Heart Rate Data

## Goal

In this challenge page, you will extend your heart rate logging and zone program so that it also:

1. publishes live heart rate values to an MQTT broker
2. uses your own device ID in the topic path
3. attempts to read the current battery state from the Polar H10

This page is intentionally less prescriptive than the earlier pages. You should use the ideas and code patterns from the rest of the lab to complete it.

## MQTT publish challenge

Use the following MQTT details:

- **Broker:** `test.mosquitto.org`
- **Port:** `1883`
- **Topic format:** `/setu/hr/<deviceID>/HR`

Replace `<deviceID>` with the device ID printed on your Polar H10.

### Example topic

If your H10 device ID is `119C6A30`, your topic would be:

```text
/setu/hr/119C6A30/HR
```

## What should be published?

Each time your program receives a heart rate value, publish a message to the MQTT topic.

Start with a very simple payload, for example just the heart rate value:

```text
72
```

Then, if you want to go further, publish a richer payload such as JSON:

```json
{"heart_rate": 72, "zone": "Zone 2", "timestamp": "2026-03-08T11:14:02"}
```

## Suggested Python package

A common Python MQTT client is `paho-mqtt`.

Install it on the Raspberry Pi if needed:

```bash
pip install paho-mqtt
```

## Battery state challenge

Now try to get the current battery level from the Polar H10.

### Hints

- The standard **Battery Service** has UUID `0000180f-0000-1000-8000-00805f9b34fb`
- The standard **Battery Level characteristic** has UUID `00002a19-0000-1000-8000-00805f9b34fb`
- You may need to inspect the services on your device before trying to read the battery characteristic
- Not every BLE device exposes every standard service in exactly the same way during every session

### Possible approach

After connecting, try something like this:

```python
BATTERY_CHAR_UUID = "00002a19-0000-1000-8000-00805f9b34fb"

battery_level = await client.read_gatt_char(BATTERY_CHAR_UUID)
print("Battery level:", battery_level[0], "%")
```

If that does not work immediately, inspect the discovered services and characteristics first.
