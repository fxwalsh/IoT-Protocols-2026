# Blynk Notifications

It would be nice to get a push notification alert to your phone every time the a Movement Event occurs. There is two ways we can do this: Event Notification sand Autmoations. This assumems you have the Blynk App installed on your Mobiule Device.

### Event Notificaiotns

+ in the BLynk Console, opent the Movement Deteection Temolate and select Evments and Notificaitons.Click the Edit Button:

<img src="./img/03.Push Notifications/image-20241202171825594.png" alt="image-20241202171825594" style="zoom:50%;" />

+ Now Select the Movement event and Select the Notifications Tab.
+ Select Enable Notifications and configure as shown below. 

<img src="./img/03.Push Notifications/image-20241202172041760.png" alt="image-20241202172041760" style="zoom:50%;" />

+ Click Save followed by Save and Apply in the BLynk Console. 
+ Now, run the program in the command line again(it might be still running). Activate the PIR - you should see/hear a push notification coming through on your device. 
+ In the Blynk Mobile App, click on the Bell icon to show notifications

### Testing Notifications

In the Blynk console, you can open the Developer Tools by openin a device and clicking on the Tools Icon ![image-20241202205516768](./img/03.Push Notifications/image-20241202205516768.png). In Developer Tools, click on the Testing tab. This gives you access to various helper tools for testing your device and developing code for devices. 

+ Select the "Log Event" option and then HTTP. This will display the URL to use to make a HTTP GET request to create an Motion Event. This will also create a push notification also. 
  <img src="./img/03.Push Notifications/image-20241202210031760.png" alt="image-20241202210031760" style="zoom:67%;" />

+ Click on the URL to copy it to the clipboard. 

+ On the command line in Raspberry Pi, you can use Curl to generate a HTTP request to the API to create a Movement Event and the associated Notification. 

  ```bash
  ~> curl "https://blynk.cloud/external/api/logEvent?token=hfhjsdkfshfhjsdkfhsdjf&code=movement_event"
  ```

  

+ You can also do this by pasting the URL into a browser. As before, this should create an event and Notification

You can create Events using the  Python library, HTTP and also MQTT. This means you can create and integrate MQTT publishers and subscibers.
