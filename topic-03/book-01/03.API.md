## API for Telemetry Data

In this part, you will create an **API** that shows:

- current soil moisture (latest telemetry)
- current relay state (latest status)
- soil moisture over the last 30 minutes

Asmall **Flask API** reads from MongoDB and the browser uses `fetch()` to poll the API every 5 seconds.

**Architecture**

```
Gateway (MQTT → Fernet decrypt → MongoDB)
              │
              ▼
         MongoDB collections
              │
              ▼
Flask API (reads MongoDB)  →  Browser (HTML/JS polls API)
```

---

## Prerequisites

- MongoDB is running locally
- Your Gateway is already storing data in MongoDB:
  - database: `setu_soil`
  - collections: `telemetry_events`, `status_events`

If you’re unsure, check MongoDB Compass:

- connect to `mongodb://localhost:27017`
- open `setu_soil` and confirm documents exist

## Step 5 — Create the Flask app (`app.py`)

Create `app.py`:

```python
from flask import Flask, jsonify, request, send_from_directory
from pymongo import MongoClient
import os
import time

app = Flask(__name__)

MONGO_URL = os.getenv("MONGO_URL", "mongodb://localhost:27017")
MONGO_DB = os.getenv("MONGO_DB", "setu_soil")

client = MongoClient(MONGO_URL)
db = client[MONGO_DB]

def minutes_ago(mins: int) -> float:
    return time.time() - mins * 60

def strip_id(doc):
    if not doc:
        return None
    doc["_id"] = str(doc["_id"])
    return doc

@app.get("/")
def home():
    return send_from_directory("static", "index.html")

@app.get("/api/latest")
def api_latest():
    telemetry = list(db["telemetry_events"].find({}).sort("sensor_ts", -1).limit(1))
    status = list(db["status_events"].find({}).sort("sensor_ts", -1).limit(1))
    return jsonify({
        "telemetry": strip_id(telemetry[0] if telemetry else None),
        "status": strip_id(status[0] if status else None),
    })

@app.get("/api/telemetry")
def api_telemetry():
    # Get the last 30 documents (most recent)
    rows = list(
        db["telemetry_events"]
          .find({"soil_moisture": {"$ne": None}})  # optional safety filter
          .sort("sensor_ts", -1)
          .limit(30)
    )

    # Put them back into time order for the chart
    rows.reverse()

    slim = [
        {"t": r.get("sensor_ts"), "m": r.get("soil_moisture")}
        for r in rows
        if r.get("sensor_ts") is not None and r.get("soil_moisture") is not None
    ]

    return jsonify({"count": len(slim), "rows": slim})

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000, debug=True)
```

## Troubleshooting

- **No telemetry yet**: confirm the gateway is inserting into `setu_soil.telemetry_events` in MongoDB Compass.
- **Chart empty**: confirm documents have numeric `soil_moisture` and `received_ts`.
- **Mongo connection errors**: ensure MongoDB is running and `MONGO_URL` is correct.
