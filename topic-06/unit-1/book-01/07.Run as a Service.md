## Part 3: Systemd service (Optional)

For a more production-like setup on your Pi 4:

1. Keep this code in your GitHub repo (`smart-doorbell`).
2. Create a systemd service:
   - `doorbell-edge.service` running `doorbell_camera.py`
3. Add a `deploy.sh` + systemd **timer** to periodically `git pull` and restart on new commits.

This lets you update the project simply by:

- Editing code locally or on another machine,
- Committing and pushing to GitHub,
- Letting the Pi automatically pull and restart.
