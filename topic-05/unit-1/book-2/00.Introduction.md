# Blynk Events

This lab explores the use of Blynk Events, Notifications and Automations. 

It will provide a means to create an event-based solution for applications and will integrate with the Raspberry Pi

In this lab you will:

+ Use Blynk.Console to define Events and Automations

+ Create Events from a Physical device and HTTPS API

+ Log and view Events

+ Configure and test  Push Notifications to the Blynk App

  

## Equipment

+ Raspberry Pi 3/4 with Grove Base Hat for Raspberry Pi
+ Grove - Red LED Button
+ Mobile Phone (Android/iPhone)
+ Blynk Account with Free tier access
