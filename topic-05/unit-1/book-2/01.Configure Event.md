## Configure Device (Raspberry Pi)

In this section, you will program the Raspberry Pi using the BLynk Python Library, to detect and send movement events to the Blynk cloud.

### Hardware setup

+ Insert the Grove Base Hat into the Raspberry Pi.
+ Connect the **Grove - Red LED Button** to digital port **D5** on the Base Hat. The Seeed Grove Base Kit for Raspberry Pi uses D5 for the LED button examples, and the digital Grove sockets are labelled with BCM pin numbers on the hat.

### Raspberry Pi Python Script

Open a terminal on the Raspberry Pi.

Create new folder called **blynk-events**  

- ```
  mkdir ~/blynk-events/
  cd ~/blynk-events/
  python -m venv .venv --system-site-packages
  ```

- Activate the venv and install the required packages for Blynk and the Grove Sensors:

  ```
  source .venv/bin/activate
  pip install https://bit.ly/3C0PMVY
  git clone https://github.com/Seeed-Studio/grove.py
  cd grove.py
  pip install .
  cd ..cd 
  
  ```

In **blynk-events**  folder, create a file called ***pir_movement.py*** script:

```python
import time

# PIR motion sensor (digital)
from grove.gpio import GPIO

PIR_PIN = 5
pir = GPIO(PIR_PIN, GPIO.IN)
last_state = 0


def read_pir():
    """Return current PIR level: 1 for motion, 0 for no motion."""
    return int(pir.read())


def is_movement_detected():
    """Return True once when PIR changes from 0 to 1."""
    global last_state

    state = read_pir()
    detected = state == 1 and last_state == 0
    last_state = state
    return detected


if __name__ == "__main__":
    while True:
        if is_movement_detected():
            print("Movement detected")
        # Short delay to prevent high CPU usage
        time.sleep(0.1)
```

On the command line, run the Python program as before (``python button_movement.py``) . 

+ Move something in front of the PIR. You should see the "Movement detected" message. 
+ Stop the program using ctrl+c in the command line.

### BLynk it up

In the same folder, create a new file called ``blynk_movement.py`` and paste in the following code:

+ **You will need to replace the auth token with the token from your Movement Detection Device in Blynk.**

```python
import BlynkLib
import time
from pir_movement import is_movement_detected

# Blynk authentication token
BLYNK_AUTH = 'YOUR TOKEN'
# Initialise the Blynk instance
blynk = BlynkLib.Blynk(BLYNK_AUTH)
VIRTUAL_PIN = 0
PULSE_SECONDS = 2.0


if __name__ == "__main__":
    pin_is_high = False
    pulse_off_at = 0.0

    # Start with V0 low.
    blynk.virtual_write(VIRTUAL_PIN, 0)

    while True:
        now = time.monotonic()
        blynk.run()

        if is_movement_detected():
            print("Movement detected")
            blynk.virtual_write(VIRTUAL_PIN, 1)
            pin_is_high = True
            pulse_off_at = now + PULSE_SECONDS

        if pin_is_high and now >= pulse_off_at:
            blynk.virtual_write(VIRTUAL_PIN, 0)
            pin_is_high = False
            print("reset to 0")

        # Keep the loop responsive for network + sensor polling.
        time.sleep(1)
```
